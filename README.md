# waznat-shahi_2
# وزنة شاهي ربيع

تطبيق ويب بسيط لحساب كمية الشاي والسكر المناسبة بناءً على كمية الماء، مع دعم وصفات مخصصة لشاهي ربيع وشاهي أبو جبل، وإمكانية تغيير الثيمات اللونية وحفظ النتائج.

## نبذة عن التطبيق

**وزنة شاهي ربيع** هو تطبيق خفيف يعمل من المتصفح، صُمم لمساعدة المستخدم على ضبط وزنة الشاي والسكر بدقة حسب كمية الماء المستخدمة.
يعتمد التطبيق على معادلات سهلة وواضحة، ويعرض النتيجة مباشرة بالجرام والملليلتر، مع واجهة عربية مريحة وسريعة الاستخدام.

التطبيق مناسب لمن يريد تحضير الشاي بوزنة ثابتة بدل الاعتماد على التقدير العشوائي.

## المميزات

* حساب كمية السكر والشاي حسب كمية الماء.
* إمكانية الحساب العكسي بناءً على كمية السكر أو الشاي.
* دعم مستويات مختلفة للسكر:

  * خفيف
  * معتدل
  * حالي
* دعم مستويات مختلفة لقوة الشاي:

  * خفيف
  * وسط
  * ثقيل
* وصفة مخصصة لخلطة شاهي ربيع.
* قسم مستقل لشاهي أبو جبل.
* عرض النتائج بشكل واضح وسريع.
* نسخ النتيجة بضغطة واحدة.
* مشاركة النتيجة عبر واتساب.
* حفظ النتائج في سجل الحسابات.
* حاسبة سكر للبيالة.
* دعم عدة ثيمات لونية.
* واجهة عربية بالكامل.
* تصميم متجاوب مناسب للجوال والكمبيوتر.
* يعمل كصفحة HTML بسيطة بدون الحاجة إلى خادم خلفي.

## طريقة الاستخدام

1. افتح التطبيق من المتصفح.
2. اختر طريقة الحساب:

   * بالماء
   * بالسكر
   * بالشاي
3. أدخل القيمة المطلوبة.
4. اختر مستوى السكر وقوة الشاي.
5. ستظهر النتيجة مباشرة.
6. يمكنك نسخ النتيجة أو مشاركتها عبر واتساب أو حفظها في السجل.

## طريقة الحساب

يعتمد التطبيق على حساب الكميات وفق النسب التالية تقريبًا:

* السكر: حسب المستوى المختار بالجرام لكل لتر.
* الشاي: حسب قوة الشاي المختارة بالجرام لكل لتر.
* الماء: يحسب بالملليلتر.

مثال عام:

```text
كمية السكر = كمية الماء بالمل ÷ 1000 × نسبة السكر
كمية الشاي = كمية الماء بالمل ÷ 1000 × نسبة الشاي
```

## الثيمات المتوفرة

يدعم التطبيق عدة ثيمات لونية يمكن التبديل بينها من زر تغيير المظهر، وتشمل:

* ثيم داكن دافئ.
* ثيم فاتح.
* ثيم بحري.
* ثيم وردي برقوقي.

يتم حفظ الثيم المختار تلقائيًا في المتصفح، بحيث يبقى مفعّلًا عند فتح التطبيق مرة أخرى.

## الملفات الأساسية

```text
index.html
script.js
assets/
```

### index.html

يحتوي على بنية الصفحة، عناصر الواجهة، تنسيق CSS، وقائمة الثيمات.

### script.js

يحتوي على منطق الحساب، إدخال القيم، تحديث النتائج، النسخ، المشاركة، والسجل.

### assets

مجلد مخصص للصور والأيقونات والملفات المساعدة المستخدمة داخل التطبيق.

## التشغيل المحلي

لا يحتاج التطبيق إلى تثبيت أو إعدادات معقدة.

يمكن تشغيله مباشرة بفتح ملف:

```text
index.html
```

داخل المتصفح.

أو تشغيله عبر إضافة Live Server في محرر Visual Studio Code للحصول على تجربة أفضل أثناء التطوير.

## النشر

يمكن نشر التطبيق بسهولة على أي استضافة صفحات ثابتة مثل:

لأن التطبيق يعتمد على HTML وCSS وJavaScript فقط.
