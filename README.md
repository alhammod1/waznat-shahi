# 🍵 وزنة شاهي ربيع

تطبيق ويب عربي بسيط وأنيق لحساب **وزنة الشاي والسكر** بدقة حسب كمية الماء، مع دعم وصفات مخصصة لشاهي ربيع وشاهي أبو جبل، وثيمات لونية متعددة، وسجل لحفظ الحسابات.

<p align="center">
  <strong>حاسبة شاي خفيفة وسريعة تعمل مباشرة من المتصفح</strong>
</p>

---

## 📌 نبذة عن التطبيق

**وزنة شاهي ربيع** هو تطبيق ويب صُمم لمساعدة المستخدم على تحضير الشاي بوزنة ثابتة وواضحة بدل الاعتماد على التقدير العشوائي.

يعتمد التطبيق على معادلات بسيطة لحساب كمية **الماء، السكر، والشاي**، ويعرض النتيجة مباشرة بطريقة سهلة القراءة، مع واجهة عربية كاملة مناسبة للجوال والكمبيوتر.

التطبيق مناسب لمن يريد ضبط طعم الشاي بشكل متكرر وثابت، سواء لشاهي ربيع أو شاهي أبو جبل أو الخلطات الخاصة.

---

## ✨ المميزات

* حساب كمية السكر والشاي حسب كمية الماء.
* إمكانية الحساب العكسي بناءً على كمية السكر أو كمية الشاي.
* **مستويات السكر:** خفيف، معتدل، حالي.
* **قوة الشاي:** خفيف، وسط، ثقيل.
* وصفة مخصصة لخلطة شاهي ربيع.
* قسم مستقل لحساب شاهي أبو جبل.
* عرض النتيجة بشكل واضح وسريع.
* نسخ النتيجة بضغطة واحدة.
* مشاركة النتيجة عبر واتساب.
* حفظ الحسابات في سجل داخلي.
* حاسبة مخصصة لسكر البيالة.
* دعم عدة ثيمات لونية.
* حفظ الثيم المختار تلقائيًا في المتصفح.
* واجهة عربية بالكامل.
* تصميم متجاوب مناسب للجوال والكمبيوتر.
* يعمل كصفحة ثابتة بدون قاعدة بيانات أو تسجيل دخول.

---

## 🎨 الثيمات المتوفرة

يدعم التطبيق عدة ثيمات لونية يمكن التبديل بينها من زر تغيير المظهر:

* داكن دافئ.
* فاتح.
* بحري.
* وردي برقوقي.

يتم حفظ الثيم المختار تلقائيًا في المتصفح باستخدام `localStorage`، لذلك يبقى الثيم مفعّلًا عند فتح التطبيق مرة أخرى.

---

## 🧮 طريقة الحساب

يعتمد التطبيق على النسبة المختارة لكل لتر ماء.

### مثال عام

```text
كمية السكر = كمية الماء بالمل ÷ 1000 × نسبة السكر
كمية الشاي = كمية الماء بالمل ÷ 1000 × نسبة الشاي
```

### مثال توضيحي

إذا كانت كمية الماء 1000 مل، وكانت نسبة السكر 75 جم/لتر، ونسبة الشاي 12 جم/لتر:

```text
الماء: 1000 مل
السكر: 75 جم
الشاي: 12 جم
```

---

## 📱 طريقة الاستخدام

1. افتح التطبيق من المتصفح.
2. اختر طريقة الحساب: بالماء، بالسكر، أو بالشاي.
3. أدخل القيمة المطلوبة.
4. اختر مستوى السكر وقوة الشاي.
5. ستظهر النتيجة مباشرة.
6. يمكنك نسخ النتيجة، مشاركتها عبر واتساب، أو حفظها في السجل.

---

## 🗂️ الملفات الأساسية

```text
index.html
script.js
assets/
```

### `index.html`

يحتوي على بنية الصفحة، عناصر الواجهة، تنسيقات CSS، وقائمة الثيمات.

### `script.js`

يحتوي على منطق الحساب، إدخال القيم، تحديث النتائج، النسخ، المشاركة، السجل، وبعض وظائف التفاعل داخل التطبيق.

### `assets/`

مجلد مخصص للصور والأيقونات والملفات المساعدة المستخدمة في التطبيق.

## 🚀 التشغيل المحلي

لا يحتاج التطبيق إلى تثبيت أو إعدادات معقدة.

يمكن تشغيله مباشرة بفتح الملف التالي في المتصفح:

```text
index.html
```

وللتطوير بشكل أفضل، يمكن تشغيله عبر إضافة **Live Server** في محرر **Visual Studio Code**.

---

## 🌐 النشر

يمكن نشر التطبيق بسهولة على أي استضافة صفحات ثابتة، مثل:

* GitHub Pages
* Firebase Hosting
* Cloudflare Pages
* Netlify
* Vercel

لأن التطبيق يعتمد فقط على:

```text
HTML + CSS + JavaScript
```

ولا يحتاج إلى خادم خلفي أو قاعدة بيانات.

## 🔒 الخصوصية

التطبيق لا يحتاج إلى تسجيل دخول، ولا يرسل بيانات المستخدم إلى أي خادم.

جميع الحسابات والثيمات المحفوظة تكون داخل متصفح المستخدم فقط باستخدام التخزين المحلي `localStorage`.

* النتائج تقريبية وقابلة للتعديل حسب الذوق الشخصي.
